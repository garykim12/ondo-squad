- **골든타임:** 스쿼드끼리 "주 2~3회, 저녁 9~11시"처럼 시간을 정해서 올리고, 나머지 팀원은 1시간 안에 인용·리트윗·댓글로 반응해 주세요.

- **스쿼드 알림방:** 스쿼드 텔레그램 단톡방에 "X 올렸어요 + 링크"를 바로 공유해 주세요. 골든타임 안에 반응하려면 이게 제일 확실해요.
- **텔레그램 → X 유도:** 내 텔레그램 채널에 "X에 정산 올렸어요, 의견 남겨주세요"와 링크를 올리면 X 글의 초반 반응을 끌어올릴 수 있어요.
